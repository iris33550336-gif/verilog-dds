Verilog DDS 波形发生器

一个使用 Verilog 实现的简单DDS波形发生器。

这个项目主要是用来学习 FPGA / Verilog 中 DDS 的基本实现方法，目前以仿真为主，通过 Testbench 产生波形，并使用 VCD 文件查看仿真结果。
因为我本人做了mini CPU的波形仿真以后，对数字电路里如何呈现正弦函数波形图像产生了兴趣，为了观察仿真波形，尝试做了这个项目。这个项目的整体结构要比mini CPU简单很多，
但是感觉有一些数电知识对我而言搞起来会很难受，因为我还没系统学这个

DDS是直接数字合成。这里是尝试用verilog数字硬件的思维去模仿dds仿真产生正弦波形和频率

DDS 的基本思路其实比较简单：

通过一个相位累加器不断累加相位值，再根据当前相位得到对应的波形幅值。

简单来说就是：

频率控制字
     ↓
相位累加器
     ↓
当前相位
     ↓
波形查找 / 波形计算
     ↓
输出数字波形

每个时钟周期，相位累加器都会增加一个固定的值。

频率控制字越大，相位变化越快，最终输出的波形频率也就越高。

因此 DDS 最大的一个特点就是：改变频率控制字就可以比较方便地改变输出频率。

项目目前主要用于 Verilog 仿真。

可以使用 Icarus Verilog 编译，然后生成 VCD 文件：

iverilog -o dds_sim dds_tb.v
vvp dds_sim

如果 Testbench 中使用了 $dumpfile 和 $dumpvars，运行后会生成：

dds.vcd

然后可以使用 GTKWave 打开：

gtkwave dds.vcd

通过 GTKWave 可以直接观察时钟、相位累加器以及输出波形的变化。
